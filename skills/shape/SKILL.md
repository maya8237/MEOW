---
name: shape
description: Optionally assess uncertain work and persist shape or breadboard artifacts.
---

Use `meow shape assess` for broad or ambiguous requests. Clear requests retain
the direct planning path. If the user accepts shaping, record the problem,
constraints, options, fit checks, chosen approach, and assumptions. For complex
UI or multi-component work, optionally record places, affordances, wiring, and
vertical slices, then run reflection. Shape artifacts are advisory inputs to
planning and review and must never silently block a clear feature request.

Use this skill when a request spans multiple components, has several plausible
approaches, leaves important constraints or assumptions open, or involves a
complex UI flow. Skip it for a precise, well-scoped request and go directly to
planning. Shaping is optional and is not an automatic planning gate.
